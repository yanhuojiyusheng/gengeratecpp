# gengeratecpp

Generating source file definitions for c++ header files using python scripts

Implemented via regular expressions

Currently it is not possible to adapt templates and class definitions within classes, but if there is a real need to do so, consider implementing the

Make sure your header files are syntactically correct!

利用python脚本实现c++头文件生成源文件定义

通过正则表达式实现

目前无法适配模板和类内的类定义，如果确实有需要可以考虑实现

请确保你的头文件符合语法规定


## use

Just accept the name of the header file as an argument
接受头文件的名字作为参数即可
